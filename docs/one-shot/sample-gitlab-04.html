特異点

SINGULARITY

One control plane for your whole fleet of coding agents for spec-driven development.

Singularity isn't trying to replace your coding agent. It's the local environment around it: live sessions, a task board where every card is a real git worktree, scheduled and background jobs, and the skills, rules, memory, config, hooks and wiki your agents read from. Plus what every run actually cost you.

01正体

WHAT THIS IS, AND WHAT IT ISN'T

Every tool in this category says "orchestrate your agents." Here is the specific, checkable version, so you can decide in thirty seconds instead of installing to find out.

IT IS是
  • ✓A local web UI plus a loopback daemon. Node, Fastify and ws on 127.0.0.1. You run it, you own it, it dies when you stop it.
  • ✓A supervisor for real PTY sessions. It spawns the coding agent binary you already have installed and streams it to a browser terminal.
  • ✓A task board built on git worktrees. A card owns a worktree, a branch and a session, so four agents work at once without touching each other's files.
  • ✓The context layer. Skills, rules, memory, config, hooks and wiki, editable in one place instead of six scattered dotfiles.
  • ✓Honest about cost. Per-session turns, tokens and dollars, read from the global statusline rather than guessed from a pricing table.
IT IS NOT否
  • ✕Not a cloud platform. There is no tenant, no upload, no hosted runner. Nothing to sign up for, nothing to churn from.
  • ✕Not another coding agent. It does not write your code and has no model of its own. It manages the environment around the agent you already chose.
  • ✕Not a terminal replacement. Your terminal still works. This is for when one terminal stopped being enough.
  • ✕Not multiplayer. It binds loopback on purpose: the daemon spawns agents with full filesystem access, so it stays on the machine that already trusts them.
  • ✕Not finished. It is v0.9, MIT, and built in the open by two people who use it daily.
02環境

THE ENVIRONMENT AROUND THE AGENT

Seventeen panels, four jobs. Nothing here is a wrapper around a prompt box: each one is a surface your agents already read from or write to, made visible and editable.

RUN稼働
  • SESSIONSLive agent PTY sessions you can attach to, interrupt and resume.
  • PROCESSESTask manager for the agent processes actually running on your machine.
  • STATUSPolled availability of upstream provider status pages.
ORGANIZE整理
  • TASKSKanban over git-worktree sessions. Worktree, branch and session per card.
  • AUTOMATIONScheduled cron jobs (UTC) and background jobs that select tasks by criteria.
  • HISTORYA core-sample of the day's work, drilled down per session, pushed live over WS.
CONTEXT文脈
  • SKILLSBrowse every skill on the machine, grouped or flat.
  • RULESView and edit the rules your agents load.
  • MEMORYProject memory, editable in place.
  • CONFIGsettings.json and settings.local.json, with backup and JSON validation.
  • HOOKSSee and edit what fires around each run.
  • WIKIYour linked notes, with wikilinks and previews.
ACCOUNT FOR計上
  • USAGE5h and 7d meters plus the full usage report.
  • TRANSCRIPTSRead back any session, tool calls included.
  • EXPLORERFile tree with tabs: browse, edit, create, rename, delete.
  • APPEARANCETheme skin plus light and dark mode.
  • SETTINGSRebind every keyboard shortcut.

05局所

LOCAL MEANS LOCAL

127.0.0.1

LOOPBACK ONLY 局所結束 MIT LICENSED

YOUR AGENTS ALREADY HAVE ACCESS TO YOUR MACHINE. THE CONTROL PLANE DOESN'T NEED TO BE ON THE INTERNET.

  • The daemon binds 127.0.0.1 and never 0.0.0.0, because it spawns agents with full filesystem access.
  • An origin allowlist blocks DNS-rebinding and drive-by browser hits to loopback.
  • Optional SING_TOKEN gates data endpoints and the WebSocket. Env var only, never persisted by the app.
  • Machine-specific config has no baked-in defaults. The daemon refuses to start rather than guess where your things are.

IF AGENTS FAIL TO SPAWN ON MACOS OR LINUX spawn failed: posix_spawnp failed means node-pty's spawn-helper lost its execute bit, which pnpm's store occasionally does on extract. Run pnpm run postinstall. It is not a CLAUDE_BIN problem.
